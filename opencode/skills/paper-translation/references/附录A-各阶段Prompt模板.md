# 附录A 各阶段 Prompt 模板

> 本附录为规范正文 0–6 七个阶段提供可直接套用的 Prompt 模板。使用时仅需替换 `{{双花括号}}` 内的变量，其余指令原样保留。模板工具无关，不依赖任何特定软件或模型。

## 使用说明

- 每个模板包含三要素：【输入 → 输出】说明输入产物与输出产物；代码块内的指令全文复制套用；模板后一行"要点"提示该阶段最容易出错的环节。
- `{{变量}}` 一律用中文描述，套用时替换为实际文件或内容；同一阶段内多次出现的同一变量必须指向同一对象。
- 阶段 3（分块翻译）为全流程核心模板，术语表硬约束与占位符化两条不可删改；其余阶段模板可按项目规模裁剪附录部分。
- 任何阶段输出不满足本阶段验收标准时，不得流入下一阶段；回传上游按缺陷单修复。

## 配套约定：占位符与上下文摘要

- **占位符约定**：分块翻译阶段统一使用 `⟦…⟧` 包裹不译物，左括号与右括号之间不得插入任何中文或空格；合并阶段原位还原后全文不得残留 `⟦` 或 `⟧`。
- **上下文摘要格式**：阶段 3 注入的 `{{前后块摘要}}` 为每个待译块提供「前一块末句译文 + 本块首句原文 + 后一块首句译文」三段，摘要本身不作为译文输出。
- **块编号约定**：阶段 1 起的每个 block 均带形如 `B0123` 的稳定编号，贯穿清洗、翻译、合并全过程，阶段 4 按此编号核对顺序与完整性。
- **产物快照**：每个阶段结束保留一份产物快照（术语表 / 结构化文本 / 清洗文本 / 分块译文 / 合并译文 / 交付文档 / 校验报告），命名含阶段号与版本，便于回溯。

## 阶段 0 术语表抽取

【输入 → 输出】`{{源文件}}` → 术语表 `{{术语表文件}}`

```text
你是术语抽取代理。通读全文 {{源文件}}（必要时配合 {{辅助资料}} 与 {{用户术语偏好}}），完成以下任务：
1. 抽取全部专有名词、缩写、机构名、图表题、高频学术词，逐条登记；
2. 输出三列表格，列头为「原文 | 译文 | 备注」；
3. 备注列必须写明：术语属性（人名/机构/缩写/图表题/普通术语）、取舍依据、歧义说明；
4. 凡无法确定译名、或需查证术语在线的条目，在备注中标注【待查】，并附建议检索关键词；
5. 缩写单独成区，标注全称与首现位置；
6. 覆盖率不低于全文专有名词与高频学术词的 95%，无歧义项有明确取舍备注；
7. 输出前自查：无重复条目、无漏登记图表题、机构名与作者名不混排。
```

要点：术语表是全文唯一术语依据，未经评审不得改动；【待查】项在评审通过前不得进入翻译环节。

## 阶段 1 结构化抽取

### 1.1 LaTeX 源码路径

【输入 → 输出】`{{LaTeX 源码}}` → 结构化文本 `{{结构化文本}}`

```text
你是结构抽取代理。解析 LaTeX 源码 {{LaTeX 源码}}，输出结构化文本：
1. 保留全部结构标记：章节层级、段落、图表环境、公式环境、文献条目、脚注、交叉引用，\cite、\ref 等命令原样保留；
2. 按正文阅读顺序输出，代码注释与编译指令不进入正文；
3. 图表题、公式编号、文献条目各归其位，编号原样保留；
4. 使用统一的 block 分隔标记，标明每个块的类型与编号；
5. 跨页或跨环境的断段处保留衔接标记，便于阶段 2 缝合；
6. 不改变任何原文文字，不做翻译；
7. 输出末尾附 block 计数清单：段落、图表、公式、文献各多少块，供后续核对。
```

### 1.2 PDF 路径

【输入 → 输出】`{{PDF 文件}}` → 结构化文本 `{{结构化文本}}`

```text
你是结构抽取代理。解析 PDF 文件 {{PDF 文件}}，输出结构化文本：
1. 按版面 block 与栏顺序抽取文本，禁止按 y/x 坐标行级排序，防止双栏交叉串栏；
2. 保留段落、标题层级、图表、公式、栏结构标记；
3. 图内文字（坐标轴刻度、图例、水印、图片内嵌文字）与正文分离，另行归入图内文字区；
4. 跨页断段处保留衔接标记，便于后续清洗缝合；
5. 编号、公式、脚注原样保留，不翻译、不修改；
6. 输出顺序必须与原文阅读顺序一致；
7. 输出末尾附 block 计数清单，与原文逐页抽查比对，确认无遗漏页。
```

要点：PDF 路径是回退方案，务必以版面块为单位抽文；顺序出错会传导到后续全部阶段。

## 阶段 2 清洗

【输入 → 输出】`{{结构化文本}}` → 「问题块清单 + 清洗文本」`{{清洗文本}}`

```text
你是文本清洗代理。清洗结构化文本 {{结构化文本}}，输出两部分：
第一部分：问题块清单，逐条列出——
1. 被误抽入正文的图内文字块（坐标轴、图例、水印等）及处置方式；
2. 跨栏、跨页被拆断的段落，及缝合后的段落编号；
3. 重复片段与空块。
第二部分：清洗文本——
1. 正文不含任何图内文字；
2. 被拆断段落已缝合为完整段落，缝合处不得臆造内容；
3. 无重复片段、无空块，段落顺序与原文阅读序一致；
4. 全部编号、公式、交叉引用原样保留；
5. 标题层级与章节顺序与原文一致，未因清洗丢失。
```

要点：清洗只处理噪音与结构，不涉及译文语义；缝合断句时严禁脑补被截断的内容。

## 阶段 3 分块翻译

【输入 → 输出】`{{清洗文本}} + {{术语表}} + {{前后块摘要}}` → 分块译文 `{{分块译文}}`

```text
你是翻译代理。按块翻译 {{清洗文本}}，严格遵守以下约束：
1. 术语表硬约束：术语必须且只能使用下表译法（{{术语表}}），100% 命中，禁止同义混用、禁止临时起名；术语表未收录的新词，先报告补表，不擅自翻译；
2. 不译物占位符化：公式、图表编号、文献条目、交叉引用等一律用 ⟦…⟧ 标记原样保留，如 ⟦式 (3)⟧、⟦\cite{smith2020}⟧、⟦图 2⟧，不得翻译、不得改动内部内容；
3. 上下文注入：翻译每个块前，先阅读提供的 {{前后块摘要}}，确保与相邻块语义连贯；
4. 忠实优先：语义忠实对应原文，严禁增删、臆造、补全原文没有的内容；句子被截断时保留截断状态，由后续块续接；
5. 图注行以「图 N | …」起首，表注、文献、脚注格式与原文一一对应；
6. 缩写首现写作「中文名（English Full Name, ABBR）」，此后统一用缩写；
7. 图表引用统一为「（图 N）」「（扩展数据图 N）」「（扩展数据表 N）」；
8. 输出保持块顺序与编号，不合并、不拆分、不重排；
9. 每个块译文后附该块对应的原文编号，便于合并阶段核对。
```

要点：本模板是全流程核心；任何一条约束缺失都可能造成术语漂移或占位符被污染。

## 阶段 4 合并校验

【输入 → 输出】`{{分块译文}} + {{原文顺序索引}}` → 合并译文 `{{合并译文}}`

```text
你是合并代理。将分块译文 {{分块译文}} 按 {{原文顺序索引}} 拼接为完整译文，并逐项自检：
1. 编号连续性：章节、图表、公式、文献、脚注编号连续无缺，与原文一一对应；
2. 漏译/重复检测：逐块核对原文与译文，无漏译块、无重复块、无错位块；
3. 跨页截断续接：被截断的句子由下一块正确续接，未臆造补全；
4. 占位符完整：全部 ⟦…⟧ 标记原样存在，位置与原文一致；
5. 粗筛比例：译文 CJK 字数与原文词数比例在合理区间，异常段落单独标记复核；
6. 只做结构整合，不做语义修改；发现问题回传上游，不得就地改稿。
```

要点：发现术语错误须回阶段 0 修订术语表后重跑，合并阶段禁止跨级修补。

## 阶段 5 输出重建

【输入 → 输出】`{{合并译文}} + {{输出模板}}` → 交付文档 `{{交付文档}}`

```text
你是输出重建代理。将 {{合并译文}} 重建为交付文档 {{交付文档}}，要求：
1. 默认双语对照：原文与译文一一对应，版式一致、对齐正确；
2. 无软换行：正文段落不得产生手动换行符（Word 中对应 <w:br/>），文本自然回流；对齐宜用左对齐，两端对齐不得制造字间大空白；
3. 图表、公式、文献、脚注结构完整保留，编号与交叉引用完好；
4. 占位符原位还原为公式、编号、文献条目等原始对象；
5. 图片、表格、公式对象不得因翻译被移动或破坏；
6. 按 {{输出模板}} 的版式要求输出，交付物为可直接排版文件；
7. 重建完成后自查：正文段落软换行计数为 0，双语对照逐段对齐无误。
```

要点：软换行是最高发坑项，重建后必须核查正文段落软换行计数为 0。

## 阶段 6 终审

【输入 → 输出】`{{全链产物}} + {{术语表}} + {{校验清单}}` → 校验报告 `{{校验报告}}`

```text
你是校验代理，独立于生产链，只读产物、只写报告。按 {{校验清单}}（规范第 5 节）逐项核查 {{全链产物}}：
1. 结构性问题：标题层级、图表/公式/文献/脚注数量与编号、漏译/重复/错位、跨页续接、软换行计数；
2. 术语与格式：术语 100% 命中 {{术语表}}、缩写首现写法、图表引用统一、图注「图 N | …」起首、占位符完整；
3. 国标符合性：GB/T 15834、GB/T 15835、GB/T 7714、GB/T 7713.2；
4. Word 输出层：双语对照版式、对齐、软换行、图片表格公式对象未被移动或破坏。
输出校验报告 {{校验报告}}：问题清单（每条注明所属阶段、严重程度、处置意见）+ 结论（通过/不通过）。命中坑项时回溯对应阶段修复后重新校验，直到全部通过。
```

要点：校验是闸门，未通过不得交付；报告须归档，遗留问题有明确处置意见。

## 通用：不译物清单

以下对象在任何阶段都不得翻译、不得改写，分块翻译时一律以 `⟦…⟧` 占位符隔离：

- 公式及其编号：如 `⟦式 (3)⟧`、`⟦\begin{equation}…\end{equation}⟧`
- LaTeX 引用命令：`\cite{…}`、`\ref{…}`、`\label{…}` 等内部标识
- 图表编号及其引用：如 `⟦图 2⟧`、`⟦Table 3⟧`、`⟦扩展数据图 1⟧`
- 文献条目：作者名、年份、期刊名、卷期页码（按 GB/T 7714 著录，不译）
- 交叉引用编号：章节号、页码、脚注号
- 单位与符号：`kg`、`m/s`、`°C`、`µ`、希腊字母与数学符号
- 标识符与代码：变量名、文件名、命令名、DOI、URL、ISSN/ISBN
- 专有编号：型号、协议号、专利号、标准号（如 GB/T 7714 本身）
- 人名与机构缩写：作者姓名、期刊缩写、机构缩写（全称可在术语表中给出，正文不译）

要点：占位符内内容视为「禁改区」；合并阶段原位还原时也不得改写其内部字符。

## 附：阶段间流转核对

| 上游产物 | 下游阶段 | 交接核对点 |
| --- | --- | --- |
| 术语表 | 3 分块翻译 | 术语命中率 100%；新词先补表后翻译 |
| 结构化文本 | 2 清洗 | block 计数与原文逐页抽查一致 |
| 清洗文本 | 3 分块翻译 | 无图内文字、无重复片段、段落完整 |
| 分块译文 | 4 合并 | 占位符完整、块编号与原文索引一致 |
| 合并译文 | 5 输出重建 | 编号连续、无漏译重复、跨页续接正确 |
| 交付文档 | 6 终审 | 软换行计数为 0、双语对照对齐 |
| 校验报告 | 归档 | 问题清单逐项闭环，结论明确 |

任一交接点不通过时，按缺陷单回传对应上游阶段修复后重新交接，禁止带病流转。
