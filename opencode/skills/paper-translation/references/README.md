# 英文论文中译处理规范

> 本文档定义将英文论文（期刊论文、预印本、学位论文等）翻译为中文的完整处理流程，覆盖从术语表预建、源文件解析、清洗、翻译、合并到输出重建与校验的全部环节。文档工具无关，任何团队或个人均可依据本规范落地实施。

## 1. 目的与适用范围

### 1.1 目的

- **建立可复现流程**：把一次性的「翻译任务」固化为 0–6 七个阶段的流水线，每一阶段都有明确目标、关键动作与验收标准。
- **保证质量四维一致**：译文在语义、术语、编号、格式四个维度保持一致，任何两段同类内容的处理结果都可比对、可审计。
- **产出可直接排版交付的文档**：默认双语对照，格式符合常见出版与学位论文要求（参考 GB/T 15834、GB/T 15835、GB/T 7714、GB/T 7713.2）。
- **支持部分翻译**：同一套流程可用于全文翻译，也可裁剪为指定章节的部分翻译。

### 1.2 适用范围

- **全文翻译**：正文、标题层级、图表及图注表注、公式、文献、脚注、附录、致谢、摘要。
- **部分翻译**：指定章节、指定图表或指定段落范围。
- **来源形态**：LaTeX 源码（优先）或 PDF（回退），两种形态都必须产出同一规范的结构化中间文本。
- **不适用**：纯口语化改写、非学术文体、受版权限制不得翻译的材料。

## 2. 总体原则

1. **一致性前置**：先建术语表，再开始翻译；术语表为全文唯一术语依据，未经评审不得随意改动。翻译过程中遇到术语表未收录的新词，先补表、后翻译，禁止临时起名。
2. **结构先于文字**：先还原原文结构（标题层级、章节、图表、公式、文献、脚注），再填充译文，保证编号与锚点完整，避免翻译后结构漂移。
3. **不译物占位符化**：公式、图表编号、文献条目、交叉引用等不译对象在分块翻译阶段以占位符隔离，避免被误改或污染，合并阶段再原位还原。
4. **版面优先**：文本顺序以版面 block 与栏顺序为准，任何行级坐标排序（如按 y、x 坐标）一律禁止，防止双栏交叉串栏。
5. **忠实优先，译意不译形**：语义忠实对应原文，句式服从中文习惯；严禁增删、臆造或补全原文没有的内容，尤其不得「脑补」被截断的句子。
6. **校验后置为闸门**：任一阶段输出未通过本阶段验收，不得流入下一阶段；最终以校验清单与验收定义为准，缺陷单逐项闭环。

## 3. 处理流水线（6 阶段）

| 阶段 | 目标 | 关键动作 | 验收标准 |
| --- | --- | --- | --- |
| 0 术语表预建 | 锁定全文术语口径 | 通读全文，抽取专有名词、缩写、机构名、图表题；建立「英文原文 / 中文译文 / 备注」三列术语表 | 术语表覆盖全文 ≥95% 专有名词与高频学术词；无歧义项有明确取舍备注 |
| 1 获取与解析 | 获得可编辑的结构化文本 | LaTeX 源码优先；无源码时以 PDF 解析回退。按版面 block 与栏顺序抽取，禁止行级 y 坐标排序 | 输出保留段落、标题、图表、公式、栏结构；顺序与原文阅读序一致 |
| 2 清洗 | 剔除噪音，恢复完整段落 | 过滤图内文字（坐标轴刻度、图例、水印）；缝合跨栏、跨页被拆断的段落 | 正文不含图内文字；被拆段落已拼接为完整段落；无重复片段 |
| 3 分块翻译 | 逐块产出忠实译文 | 按块注入上下文（相邻块、段落主题）；术语表硬约束；公式/图表/文献/交叉引用占位符化 | 译文语义忠实、术语 100% 命中术语表；占位符原样保留；无软换行 |
| 4 合并 | 拼接为完整译文 | 按原文顺序合并各块；检查编号完整；检测漏译与重复；跨页截断处忠实续接 | 编号连续无缺；无漏译/重复块；跨页句子由下一块正确续接 |
| 5 输出重建 | 生成交付文档 | 默认生成双语对照（原文/译文对齐）；输出无软换行；保持图表、文献、脚注结构 | 双语对照版式一致；正文段落无软换行符；编号、交叉引用完好 |
| 6 校验 | 终审把关 | 按第 5 节校验清单逐项核查；命中坑项时回溯对应阶段修复 | 校验清单全项通过；达到第 6 节验收定义 |

### 3.1 阶段间流转规则

- 上游输出契约即下游输入契约；下游验收不通过时，上游必须出具缺陷单并修复后重新交接。
- 每阶段必须留下产物快照，便于回溯定位问题来源（术语表 / 结构化文本 / 清洗文本 / 分块译文 / 合并译文 / 交付文档）。
- 任何阶段禁止跨级改稿：合并阶段发现术语错误，回第 0 阶段修订术语表后再重跑翻译，不得就地修补。

## 4. 代理分工与交接契约

| 阶段 | 角色 | 权限（读/写） | 输入契约 | 输出契约 | 校验归属 |
| --- | --- | --- | --- | --- | --- |
| 0 术语表预建 | 检索代理 | 读：全文；写：术语表 | 源文件、用户术语偏好 | 术语表文件（三列结构，含备注） | 校验代理 |
| 1 获取与解析 | 抽取代理 | 读：源文件；写：结构化文本 | 源文件（LaTeX 或 PDF） | 结构化文本（保留 block/栏/结构标记） | 校验代理 |
| 2 清洗 | 抽取代理 | 读：结构化文本；写：清洗后文本 | 结构化文本 | 清洗后文本（无图内文字、段落完整） | 校验代理 |
| 3 分块翻译 | 翻译代理 | 读：清洗文本、术语表；写：分块译文 | 清洗文本 + 术语表 + 上下文注入要求 | 分块译文（占位符完整、术语命中） | 校验代理 |
| 4 合并 | 合并代理 | 读：分块译文；写：合并译文 | 分块译文 + 原文顺序索引 | 合并译文（编号完整、无漏译重复） | 校验代理 |
| 5 输出重建 | 合并代理 | 读：合并译文；写：交付文档 | 合并译文 + 输出模板（默认双语对照） | 交付文档（Word/Markdown，无软换行） | 校验代理 |
| 6 校验 | 校验代理 | 读：全链产物；写：校验报告 | 各阶段产物 + 术语表 + 校验清单 | 校验报告（问题清单、通过/失败结论） | 校验代理自审 |

### 4.1 角色说明

- **检索代理**：负责术语与背景信息检索，产出术语表，不参与译文撰写。
- **抽取代理**：负责解析与清洗，只处理结构与噪音，不涉及译文语义。
- **翻译代理**：负责分块翻译，受术语表硬约束，不改变结构与编号。
- **合并代理**：负责块级拼接与输出重建，不做语义性修改，只做结构整合。
- **校验代理**：全程只读产物、只写校验报告，独立于生产链，确保客观把关。

交接要点：上游输出契约即下游输入契约；下游发现上游缺陷时回传缺陷单，修复后重新交接，不允许带病流转。

## 5. 校验清单

### 5.1 结构性问题
- [ ] 标题层级完整，章节顺序与原文一致
- [ ] 图表、公式、文献、脚注数量与原文一致，编号连续无缺
- [ ] 无漏译段落、无重复段落、无错位块
- [ ] 跨页截断句子由下一块正确续接，未臆造补全
- [ ] 正文段落软换行符（`<w:br/>`）计数为 0

### 5.2 术语与格式
- [ ] 术语 100% 命中术语表，无同义混用
- [ ] 缩写首现写法为「中文名（English Full Name, ABBR）」，后续统一用缩写
- [ ] 图表引用统一为「（图 N）」「（扩展数据图 N）」「（扩展数据表 N）」
- [ ] 图注行以「图 N | …」起首，表注、文献、脚注格式一致
- [ ] 公式、交叉引用等不译物以占位符形式原样保留

### 5.3 国标符合性
- [ ] GB/T 15834：标点符号用法（书名号、引号、顿号、省略号等）
- [ ] GB/T 15835：出版物上数字用法
- [ ] GB/T 7714：文后参考文献著录规则
- [ ] GB/T 7713.2：学位论文编写规则（章节、图表、式编排）

### 5.4 Word 输出层
- [ ] 默认双语对照版式正确，原文与译文一一对应
- [ ] 两端对齐未产生字间大空白；对齐宜用左对齐
- [ ] 段落无软换行，文本自然回流
- [ ] 图片、表格、公式对象未因翻译被移动或破坏

## 6. 验收定义（Definition of Done）

- [ ] 术语表已建并通过评审
- [ ] 结构化文本按版面 block/栏顺序解析，顺序与原文一致
- [ ] 清洗后正文无图内文字、无重复片段、段落完整
- [ ] 分块译文语义忠实，术语命中率 100%，占位符完整
- [ ] 合并译文编号完整，漏译与重复检测通过
- [ ] 交付文档为双语对照，无软换行，对齐正常
- [ ] 第 5 节校验清单全部勾选通过
- [ ] 校验报告已归档，遗留问题有明确处置意见
- [ ] 原文中译全流程已闭环，无带病交付

## 7. 常见坑与对策

| 常见坑 | 现象 | 对策 |
| --- | --- | --- |
| 双栏 PDF 按 (y,x) 行级排序 | 左右栏逐行交叉（串栏），语义错乱、出现重复片段 | 按版面 block 与栏顺序抽取文本，禁止行级坐标排序 |
| 图内文字被抽成正文 | 坐标轴刻度、图例等混入正文 | 解析后按版面块过滤图内文字，仅保留正文块 |
| 行尾被转成手动换行符（Word `<w:br/>`） | 两端对齐把每个截断行拉伸到整行宽，字间出现大空白 | 去除软换行使文本自然回流；对齐宜用左对齐；校验正文段落 `<w:br/>` 计数为 0 |
| 跨页句子被截断 | 误以为漏译而补全 | 属正常现象，译文忠实对应并由下一块续接，不得臆造补全 |
| 图表引用格式不统一 | 「图N」「Fig. N」「扩展图N」混用 | 统一为「（图 N）」「（扩展数据图 N）」「（扩展数据表 N）」；图注行以「图 N | …」起首 |
| 缩写首现不规范 | 缩写无中文名或全称 | 首现按「中文名（English Full Name, ABBR）」书写，此后统一用缩写 |
| 漏译难以发现 | 个别段落被遗漏 | 粗筛：译文 CJK 字数与原文词数比例合理 + 逐页编号/关键词覆盖核对 |
